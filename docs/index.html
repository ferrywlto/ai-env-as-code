Get started

Build it yourself.

The first supported platform is macOS on Apple silicon. You need Git, the .NET 10 SDK, and Xcode Command Line Tools to build; the installed Native AOT executable does not require the .NET runtime. 

git clone https://github.com/ferrywlto/ai-env-as-code.git
cd ai-env-as-code
./scripts/build-osx-arm64.sh
./scripts/install-osx-arm64.sh
aec init --repo /absolute/path/to/aec-data
